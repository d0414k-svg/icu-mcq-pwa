# ICU MCQ PWA Delivery

This package contains a local-only, iPhone-first PWA for personal ICU MCQ study.

## What to deploy

Deploy the contents of `dist/` to any HTTPS static host:

- Vercel
- Netlify
- Cloudflare Pages
- GitHub Pages
- Any HTTPS static file server

The app shell may be hosted publicly. Imported questions, explanations, notes, attempts, and backups stay on the user's device in IndexedDB and local JSON files.

## iPhone use

1. Open the HTTPS app URL in iPhone Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch ICU MCQ from the Home Screen.
5. Import CSV from Files.
6. Export backup JSON regularly from Settings.

## Safety

Do not commit or deploy real exam questions, official explanations, source PDFs, screenshots, or extracted copyrighted content. Only fictitious sample data is included.
