# ICU MCQ PWA

集中治療科専門医試験の自習を想定した、個人利用・ローカル完結のMCQ学習PWAです。iPhoneのSafariからホーム画面に追加して使うことを主目的にしています。

## 利用方針

- 問題文、解説本文、画像はリポジトリに含めません。
- 本アプリは問題・解説の配布、共有、販売を目的としません。
- ユーザーが正当に入手した資料だけを、本人端末内のIndexedDBに取り込んで管理します。
- 公開できるのはアプリの静的シェルだけです。ユーザーが取り込んだ問題、解説、メモ、履歴、画像は端末外へ送信しません。
- AI解説生成、OCR、ログイン、クラウド同期、共有、決済はv1対象外です。

## 開発

```bash
npm ci
npm run dev
npm test
npm run build
npm audit --omit=dev
```

開発サーバーは通常 `http://127.0.0.1:5173` で起動します。

## 本番ビルドと静的デプロイ

```bash
npm run build
```

生成物は `dist/` に出力されます。Vercel、Netlify、Cloudflare Pages、GitHub Pages などの静的ホスティングへ配置できます。

GitHub Pagesなどサブパス配信を使う場合は、Viteの `base` 設定またはホスティング側の配信パスを確認してください。アプリ内のサンプルCSV読み込みとアイコン参照は `BASE_URL` 対応です。

## Netlify自動デプロイ

このリポジトリには `netlify.toml` を含めています。NetlifyにGitHubリポジトリを接続すると、`main` ブランチへのpushごとに自動で `npm run build` が実行され、`dist/` が公開されます。

1. 実問題、公式解説、PDF、バックアップJSON、`outputs/`、`private_data/` がコミット対象に入っていないことを確認します。
2. GitHubにこのプロジェクトをpushします。
3. Netlifyで `Add new project` から `Import an existing project` を選びます。
4. GitHubを選び、このリポジトリを選択します。
5. Build command は `npm run build`、Publish directory は `dist` にします。`netlify.toml` があるため通常は自動で読み取られます。
6. Deployします。以後は `main` にpushするとNetlifyが自動で再デプロイします。

Netlifyに公開されるのはアプリ本体だけです。ユーザーが取り込む問題、解説、メモ、履歴、画像は各端末のIndexedDBに保存され、Netlifyへアップロードされません。

## iPhone Home Screen インストール

1. HTTPSで公開されたアプリURLをiPhoneのSafariで開きます。
2. 共有ボタンをタップします。
3. 「ホーム画面に追加」を選びます。
4. ホーム画面の `ICU MCQ` アイコンから起動します。
5. ファイルアプリからCSVを取り込みます。
6. 設定画面から定期的にバックアップJSONを書き出します。

PWAとService WorkerはHTTPSまたはlocalhostで有効になります。iPhone実機で確認する場合は、必ずHTTPS配信URLを使ってください。

## 学習機能

- 演習画面では、問題セット内の進捗、問題ジャンプ、前後移動、問題パスを表示します。
- 問題パスは `取込元 / 年度 / 問番号 / ページ` の形式です。例: `PDF / 2026年 / 問12 / p.8`
- ブラウザの仕様上、端末内ファイルの完全なローカルパスは自動取得できません。PDF名や資料名は `source_note` または管理画面の「出典メモ」に保存してください。
- 各問題には、正解数、誤答数、正答率、連続正解、復習期限が表示されます。
- 複数正答問題では、必要な選択数と現在の選択数を表示し、必要数を満たすまで回答できません。
- 復習画面では、未回答のまま「答えを見る」を押して正答と解説を確認できます。
- 回答後は、キーだけでなく「あなたの回答」と「正答」の選択肢本文も表示します。
- 管理画面では、問題ID、問題パス、状態、選択肢数、正答数、正答率を見ながら検索・編集できます。

## CSV形式

必須列:

```text
question_id,year,number,stem,choices,correct_answers,answer_mode,status,explanation_source
```

任意列:

```text
explanation,tags,source_type,source_note,page,updated_at
```

`choices` と `correct_answers` はJSON文字列または簡易形式を受け付けます。

```csv
question_id,year,number,stem,choices,correct_answers,answer_mode,status,explanation_source,explanation,tags
2026-001,2026,1,"架空問題","A. 選択肢A || B. 選択肢B","A",single,active,manual,"ローカル取込解説","循環,架空"
```

同梱の `public/samples/fictitious_questions.csv` は架空サンプルです。実際の試験問題ではありません。

## PDFから下書き抽出

取込画面の「PDFから下書き抽出」で、自分のPDFを選択できます。

- PDFは端末内のブラウザで処理され、サーバーへ送信されません。
- テキスト選択できるPDFに対応します。
- スキャンPDFや画像だけのPDFはOCR未対応のため抽出できません。
- 抽出結果はまず `draft` として保存されます。
- 管理画面で問題文、選択肢、正答、解説、タグを確認し、状態を `出題` に変えると演習で解けます。
- 実際の問題や解説を含むPDF、抽出データ、バックアップJSONはコミットしないでください。

## バックアップ/復元

- 設定画面の「書き出し」で、問題、解説、回答履歴、復習状態、メモ、画像、取込履歴、設定をJSONに保存します。
- ブラウザストレージは端末やブラウザ設定の影響を受けるため、試験前は特に定期バックアップしてください。
- 復元時は、現在のデータを自動的に書き出してから、選択したバックアップで端末内データを置き換えます。
- 不正なバックアップJSONは復元前に拒否され、既存データは消えません。

## 取込履歴の削除

- 取込画面の「取込履歴」から、そのCSVで追加された問題一式を削除できます。
- 削除時は、対象問題、回答履歴、復習状態、メモ、画像、取込履歴をまとめて削除します。
- 削除できるのは、問題ID一覧が記録された新しい取込履歴です。古い履歴に削除対象IDがない場合は、管理画面から個別に編集してください。
- 同じ `question_id` を後から別CSVで置き換えた場合、古い取込履歴の削除で新しい問題まで消えないように、取込ジョブIDで保護しています。

## オフライン確認

1. `npm run build` でビルドします。
2. HTTPSの静的ホスティングへ `dist/` を配置します。
3. iPhone Safariで開き、ホーム画面に追加します。
4. ホーム画面から起動してサンプルCSVを取り込みます。
5. 一度アプリを閉じ、機内モードをオンにします。
6. ホーム画面から再起動し、アプリシェルと既存IndexedDBデータが表示されることを確認します。
